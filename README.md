# python-portfolio
# Project 1: Multiplication Quiz
**Summary**: This program generates five random multiplication questions using numbers between 1 and 10. The user is prompted to answer each question, and the program checks if the answer is correct. The score is updated based on the user's answers, and the final score out of 5 is displayed at the end
**Key Features**: 
- An interesting aspect of this project is its use of random to generate different questions each time the quiz is run, making it a dynamic and engaging way to practice multiplication.

### Project 2: Simple Calculator
**Summary**: This project is a simple calculator program written in Python. It allows the user to perform basic arithmetic operations: addition, subtraction, multiplication, and division. The user is prompted to choose an operation and input two numbers, and the program then prints the result of the operation. The program continues to run in a loop until the user chooses to quit.
**Key Features**: 
- An interesting aspect of this project is its simple use of functions to handle mathematical operations, which makes the code easy to understand.

 # Project 3: Power Ranger Generator
**Summary**: This project is a name generator that determines which Power Ranger you are based on a series of personality questions. The user is asked a series of questions about their traits, such as whether they see themselves as a leader or follower, and whether they are serious or silly. Based on the user's answers, the program assigns them a Power Ranger color. 
**Key Features**: 
- An interesting aspect of this project is its use of conditional statements to create a decision tree, which makes the quiz interactive as well as personalized.

# Project 4: MadLibs
**Summary**: This project is a Mad Libs game written in Python. It prompts the user to input various words, such as a location, an animal, an adjective, a noun, and a verb. These inputs are then used to fill in the blanks of a pre-defined story template, creating a unique and often humorous story based on the user's choices.  
**Key Features**: 
- An interesting aspect of this project is its interactive nature, allowing users to create a personalized story each time they play.

# Project 5: Pokemon
**Summary**: This project is a Pokémon Evolution game written in Python. The player can choose to train their Pokémon, engage in gym battles, and display Pokémon information.  The Pokémon starts at level 0 and evolves as it gains levels through training and battles. The Pokémon evolves from Pichu to Pikachu at level 10, and from Pikachu to Raichu at level 20.
**Key Features**: 
- An interesting aspect of this project is the use of random outcomes for gym battles, which adds an element of chance to the game. The evolution is also based on levels which adds a fun progression system making players want to continue to play.
